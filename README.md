# The Excuse That Almost Works

One line: the text a gamer sends the boss to skip work during GTA 6 launch week. No dead grandma, no flat tyre, no sudden fever — just a lift that died between floors and a fire crew quoting forty minutes, which is exactly the kind of boring, checkable-sounding detail a tired manager almost believes.

> Sorry, lift broke, I'm stuck between floors and the fire crew says 40 mins. Will update when I'm out.
